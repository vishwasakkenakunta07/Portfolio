# Akkenakunta Vishwas — Portfolio
Responsive portfolio built with HTML, CSS, and JavaScript. No build tools or dependencies required.

## Add your photo to the Home section
1. Put your photo in the `assets` folder.
2. Name it `profile.jpg`.
3. The path should be `assets/profile.jpg`.
4. Refresh `index.html` in your browser.

The Home section already contains a photo placeholder. You do not need to change any other section to add your photo.

## Later customizations
- Replace the email and phone placeholders in `index.html`.
- Add certificate URLs, project repositories, and your resume when ready.
- Open `index.html` directly in a browser to preview.
